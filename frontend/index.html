📑 Technical Architecture & Project Whitepaper

Architectural blueprints, safety guarantees, KDD methodology, and college viva defense topics.

🏗️ 5-Layer Decoupled Architecture

Traditional AI wrappers pass questions directly to LLMs for calculation, causing arithmetic hallucination, or run LLM-generated code via eval(), creating critical injection vulnerabilities.

ADAA solves this with strict layer separation:

  1. NLP Intent Classifier: Scikit-Learn TF-IDF + Logistic Regression categorizes question intent across 11 classes.
  2. Structured Query Planner: Local Ollama (llama3.2) or deterministic heuristic parser translates query to whitelisted JSON.
  3. Analysis Engine: Pandas and NumPy calculate exact mathematical results with zero code execution.
  4. Visual Engine: Matplotlib generates publication-grade statistical charts.
  5. Presentation Layer: Conversational responses with evidence grounded in tabular calculations.

🔄 Complete KDD Methodology

  • Stage 1: Selection: Subsetting columns, row slicing, sampling, heuristic ID and target label detection.
  • Stage 2: Preprocessing: Median/mean/mode imputation, IQR outlier capping, whitespace trimming, casing normalization.
  • Stage 3: Transformation: Min-Max scaling, Z-score standardization, discretization, one-hot encoding, domain features.
  • Stage 4: Data Mining: Pearson/Spearman correlations, K-Means clustering, Decision Tree & Logistic Regression classification.
  • Stage 5: Interpretation: Plain English insights, interactive charts, and one-click modified CSV export.
